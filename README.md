## 🚀 Featured Projects

### 1. GenAI Interview Preparation Platform

An AI-powered interview preparation platform that analyzes resumes and job descriptions to generate personalized interview reports, job match scores, technical and behavioral questions, skill-gap analysis and day-wise preparation plans. Also generates ATS-friendly resumes in PDF format.

**Tech Stack:** Gemini API · Node.js · Express · MongoDB · Zod · JWT · Puppeteer

[![Live Demo](https://img.shields.io/badge/Live-Demo-9b59b6?style=flat-square&logo=vercel)](https://genai-interview-preparation.vercel.app/)
[![Source Code](https://img.shields.io/badge/Source-Code-black?style=flat-square&logo=github)](https://github.com/suhanigupta786/genai-interview-preparation)

### 2. ARIS – Predictive Churn Analysis

A machine learning project focused on identifying customers likely to churn. Includes exploratory data analysis, Logistic Regression and Random Forest classifiers, hyperparameter tuning, cross-validation and feature importance visualizations to support customer retention decisions.

**Tech Stack:** Python · Pandas · Scikit-learn · Seaborn · Matplotlib · Streamlit

[![Live Demo](https://img.shields.io/badge/Live-Demo-9b59b6?style=flat-square&logo=streamlit)](https://arischurnai.streamlit.app/)
[![Source Code](https://img.shields.io/badge/Source-Code-black?style=flat-square&logo=github)](https://github.com/AgrimaOjha/ARIS)

### 3. OLA Business Analysis Dashboard

An interactive Tableau dashboard built using approximately 50,000 ride-hailing bookings. Analyzes peak demand hours, cancellation patterns, vehicle-wise performance and revenue trends to generate actionable business insights.

**Tech Stack:** Python · Pandas · NumPy · Jupyter Notebook · Tableau

[![Live Dashboard](https://img.shields.io/badge/Live-Dashboard-9b59b6?style=flat-square&logo=tableau)](https://public.tableau.com/app/profile/suhani.gupta2725/viz/OLABusinessDashboardAnalysis/Dashboard1)
[![Source Code](https://img.shields.io/badge/Source-Code-black?style=flat-square&logo=github)](https://github.com/suhanigupta786/SectionE_G9_OlaDataset)

### 4. Prescripto – Doctor Appointment Platform

A full-stack doctor appointment booking application featuring separate patient, doctor and admin dashboards. Includes appointment scheduling, doctor availability, role-based authentication, online payments and image uploads.

**Tech Stack:** React · Node.js · Express · MongoDB · Razorpay · Cloudinary

[![Live Demo](https://img.shields.io/badge/Live-Demo-9b59b6?style=flat-square&logo=render)](https://prescripto-frontend-llch.onrender.com)
[![Source Code](https://img.shields.io/badge/Source-Code-black?style=flat-square&logo=github)](https://github.com/suhanigupta786/Prescripto)
